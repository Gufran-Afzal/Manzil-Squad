# Student travel website

A static website for a Lahore-based student group-travel brand, starting with a proposed weekend trip to Nathiagali and Ayubia. It builds to plain HTML, CSS and JavaScript and is hosted free on GitHub Pages. No server, database or paid service is needed.

> **Pre-launch.** The brand name, contact details, trip dates and final price are placeholders. Nothing on the site claims a confirmed trip, licence, supplier or testimonial. Work through [docs/SETUP_CHECKLIST.md](docs/SETUP_CHECKLIST.md) before launch.

This project grew out of the architecture of the earlier Portfolio project (shared partials, JSON and Markdown content, a zero-dependency `build.mjs`, relative links). [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) explains what was kept and what changed.

## Quick start

You need [Node.js](https://nodejs.org) 20 or newer.

```bash
npm run dev          # build with setup warnings shown on the pages, then preview at http://localhost:4173
npm run build        # production build into dist/
npm run preview      # preview dist/ at http://localhost:4173
```

`npm install` is **only** needed for the optional image tools (it installs `sharp`). The website itself has no dependencies.

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Development build (shows a "Setup" panel listing unfinished items) and local preview |
| `npm run build` | Production build into `dist/`. Validates all content first and checks every internal link last; fails with a clear message if anything is wrong |
| `npm run build:release` | Same, but fails if launch placeholders remain (brand name, contact details, forms off, policies unreviewed…) |
| `npm run preview` | Serves `dist/` at http://localhost:4173 |
| `npm run preview:base` | Serves `dist/` at http://localhost:4173/student-travel-site/ to imitate a GitHub Pages project site |
| `npm run validate` | Checks content files only (JSON, Markdown, images, references) and lists what still needs configuring |
| `npm run check-links` | Checks internal links, images, scripts and stylesheets in `dist/` |
| `npm run sitemap` | Rebuilds `dist/sitemap.xml` (the build already does this when `siteUrl` is set) |
| `npm test` | WhatsApp unit tests, Apps Script tests, build and link check |
| `npm run mock:forms` | A local stand-in for the Google Sheets endpoint, to try the forms (see below) |
| `npm run images:art` | Regenerates the placeholder landscape artwork (needs `npm install`) |
| `npm run images:optimize` | Turns photos in `assets/img/originals/` into responsive WebP files (needs `npm install`) |
| `npm run test:browser` | Optional end-to-end tests in Chromium (see [docs/TESTING.md](docs/TESTING.md)) |

## Where things live

| You want to change… | Edit this |
|---|---|
| Brand name, contact details, social links, forms, analytics | `content/site.json` |
| A trip (dates, price, itinerary, status) | `content/trips.json` |
| A destination guide | `content/destinations.json` |
| Questions and answers | `content/faqs.json` |
| A journal article | `content/articles/<slug>.md` |
| Privacy, terms, cancellation, safety pages | `content/pages/*.md` |
| Founders | `content/team.json` |
| Testimonials (real, with consent only) | `content/testimonials.json` |
| Gallery | `content/gallery.json` |
| Every image's file, alt text, source and licence | `content/images.json` |
| Homepage, About, How we plan, Booking, Contact wording | `pages/*.html` |
| Header, footer | `partials/header.html`, `partials/footer.html` |
| Colours, fonts, spacing | `css/design-tokens.css` |

Never edit files in `dist/`: they are regenerated by every build.

## Folder structure

```
build.mjs                  the site generator (run with npm run build)
content/                   everything you normally edit: JSON, Markdown articles, policy pages
pages/                     hand-written page templates (homepage, about, booking, contact…)
partials/                  header, footer, <head>, floating WhatsApp button
css/                       design tokens + one stylesheet per area
js/                        small ES modules, loaded only on pages that need them
assets/                    fonts, icons, SVG motifs, images
scripts/                   build helpers, tests, preview server, image tools
integrations/google-apps-script/Code.gs   the Google Sheets endpoint
tests/browser.mjs          optional browser tests
docs/                      setup, content, deployment and testing guides
.github/workflows/deploy.yml   builds and publishes to GitHub Pages
dist/                      build output (not committed)
```

## Forms and WhatsApp

- **Registration and contact forms** can save to a Google Sheet through a free Google Apps Script. They start **switched off** (`"forms": { "mode": "off" }`), in which case the forms offer WhatsApp and email instead. Set up: [docs/GOOGLE_SHEETS_SETUP.md](docs/GOOGLE_SHEETS_SETUP.md).
- **WhatsApp buttons** appear once you add your number to `content/site.json`. Set up: [docs/WHATSAPP_SETUP.md](docs/WHATSAPP_SETUP.md).

Try every form state on your own computer, with no Google account:

```bash
npm run mock:forms                                      # terminal 1
FORMS_ENDPOINT=http://localhost:4174/exec npm run dev   # terminal 2 (macOS/Linux)
# Windows PowerShell: $env:FORMS_ENDPOINT="http://localhost:4174/exec"; npm run dev
```

## Deploying

Push to the `main` branch; GitHub Actions builds and publishes the site. One-time setup and custom domains: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
